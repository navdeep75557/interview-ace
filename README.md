# InterviewAce AI

InterviewAce AI is a web application that helps software engineering students practice technical interviews in a structured way.  
Users can select their role and experience level, answer interview questions, and receive AI-based feedback to improve over time.

## Features
- Role-based interview practice (Frontend, Backend, Full Stack)
- Experience level selection (Beginner, Intermediate, Advanced)
- Answer evaluation with feedback and score
- Improvement suggestions and sample answers
- Interview history and progress tracking

## Tech Stack
- Frontend: React, TypeScript, Tailwind CSS
- Backend: Node.js, Express
- Database: MongoDB
- AI Integration: OpenAI API

## Why I Built This
I built this project to simulate real interview scenarios and improve my own interview preparation.  
It also helped me understand how to integrate AI into a full-stack application and design user-focused features.
